# Security Policy

## Supported Versions

Frontend Analysis has not yet published a stable release. Security reports are
evaluated against the current repository state and any published pre-release
versions. Support and remediation decisions are based on impact,
reproducibility, and the project's current status.

Stable support guarantees will be documented separately if and when stable
releases exist.

## Reporting a Vulnerability

Use GitHub Private Vulnerability Reporting as the primary reporting method. On
this repository's **Security** tab, select **Report a vulnerability** to submit
a private report.

Do not report suspected vulnerabilities through public Issues, Pull Requests,
Discussions, or other public channels. Keep sensitive reproduction details,
exploit code, credentials, and data that could identify affected users or
systems within the private reporting channel. Redact unrelated private data.

## What to Include

Include as much of the following information as is safely available:

- a concise description of the vulnerability;
- the affected commit, branch, tag, release, or version, when known;
- reproduction steps or a minimal proof of concept;
- the expected and observed behavior;
- the security impact and realistic conditions required for an attack;
- the affected environment or platform;
- a suggested mitigation, when available; and
- whether the report or any details have already been disclosed elsewhere.

## Communication and Coordination

The maintainer will review submitted reports, communicate through the private
advisory or reporting channel, and request clarification when necessary.
Remediation and disclosure will be coordinated based on severity, impact,
reproducibility, and project circumstances. This policy does not establish a
fixed response or remediation deadline, a monetary reward, or a bug bounty.

## Coordinated Disclosure

Please avoid public disclosure until the report has been evaluated, a
mitigation or fix is available where practical, and a disclosure plan has been
coordinated. This is not a request for indefinite secrecy. Public disclosure
timing depends on impact, remediation status, and coordination between the
reporter and the maintainer.
