## Rust Bootstrap Status

`YT-TechDev/frontend-analysis` is the initial Core-focused Rust workspace owner;
this role does not establish a permanent monorepo. The root virtual workspace
currently has zero workspace members and zero crates.

Rust `1.97.1` is pinned for reproducible development and CI, but the pin is not
an MSRV promise. Accepted [ADR 0001](docs/decisions/0001-repository-topology-and-workspace-ownership.md)
and [ADR 0002](docs/decisions/0002-rust-bootstrap-toolchain-and-validation-policy.md)
own the normative decisions. See the [documentation index](docs/README.md) for
detailed setup and validation guidance.
