## Completion, Refusal and Unsupported Meaning

- A public CLI report does not establish whole-language validity or complete
  input support. Unsupported/recovery/resource-limited regions must not be
  converted to negative whole-source conclusions.
- Retained raw source and recognition-owned anchors remain the evidence
  authority; authored spelling, interpreted value, constructed identity,
  semantic/static placement and browser/runtime identity must not be conflated.
- ECMAScript `Complete { relations }` (including zero relations),
  `UnsupportedCoverage`, selected grammar/static rejection, resource limitation
  and returned internal failure are distinct outcomes. The 2026-08 [post-#343
  `9 / 184` checkpoint](javascript/2026-08-post-343-selected-ecmascript-research-checkpoint.md)
  is **historical**, not current selected reachability. The 37/193/183/10
  frozen structural inventory is not global selected completion.
  **Current aggregate selected-completion theorem: NOT ESTABLISHED**; that
  remains non-blocking for the bounded public Product question.
- HTML does not claim general fragment/template/table/formatting/foreign-content
  processing, script reentrancy, general PI parsing or DOM equivalence.
  CSS does not claim selector matching, cascade, computed/used values, CSSOM,
  layout or rendering. ECMAScript does not claim general parser/runtime/module
  semantics. No Browser Adapter/runtime analysis or cross-domain consumer is
  implemented or inferred from these four commands.
